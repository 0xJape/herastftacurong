# HERA Application Features

| Feature | Purpose | Description |
|---|---|---|
| Home Dashboard | Central Overview | Displays cycle status, latest health readings, wellness score, AI insights, alerts, and wearable status. |
| Cycle Tracker | Menstrual Monitoring | Supports period logging, cycle phase tracking, predictions, symptoms, and cycle history. |
| Daily Check-In | Wellness Logging | Records mood, stress, energy, sleep, symptoms, hydration, and wellness observations. |
| Health Monitoring | Physiological Monitoring | Displays heart rate, SpO₂, activity, wear status, and future supported indicators. |
| Nutrition Intelligence | Wellness Guidance | Provides personalized nutrition and hydration guidance based on cycle phase, activity, symptoms, and user records. |
| Hormonal Risk Assessment | Risk Awareness | Identifies unusual patterns and provides non-diagnostic risk-awareness alerts. |
| Health History & Analytics | Historical Analysis | Displays graphs and trends for menstrual, wellness, symptom, and wearable data. |
| AI Assistant / LLM Agent | Intelligent Assistance | Uses relevant HERA data as context to provide personalized, non-diagnostic explanations and guidance. |
| Notifications | Alerts and Reminders | Provides cycle, check-in, wellness, wearable, and risk-awareness notifications. |
| User Profile | User Management | Stores personal information, preferences, and application settings. |
| Wearable Connection | Device Management | Manages connection, synchronization, sensor status, and future battery information. |
| Sensor Data Feed | Current Data | Provides current synchronized wearable measurements to the app. |
