# HERA Hardware and Firmware

## Current Hardware

| Component | Purpose |
|---|---|
| ESP32-S3 | Main wearable controller |
| MAX30102 | Heart rate and SpO₂ |
| QMI8658 | Motion and activity sensing |
| ST7789 TFT | Wearable display |
| Buttons | Controls and navigation |
| NeoPixel | Status and heartbeat indicator |

## Current Firmware Features

- Heart-rate detection
- BPM averaging
- SpO₂ processing
- Wear detection
- Activity classification
- Health screen
- Activity screen
- Button controls
- Deep sleep
- Backlight timeout
- NeoPixel heartbeat pulse

## Activity Classes

- Resting
- Light
- Walking
- Active
- Vigorous
