# HERA Notifications and Alerts

## Categories

### Cycle
- Period reminder
- Cycle phase update

### Daily Check-In
- Missing check-in reminder

### Wellness
- Hydration
- Rest
- Activity reminder

### Wearable
- Disconnected device
- Synchronization needed
- Sensor unavailable
- Low battery when implemented

### Risk Awareness
- New unusual pattern
- Persistent pattern
- Consultation recommendation

## Priority

- Informational
- Reminder
- Attention
- High Attention

Alerts should explain why they were generated and should avoid diagnostic wording.
