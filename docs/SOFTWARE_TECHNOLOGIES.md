# HERA Software Technologies

| Name | Purpose | Detail |
|---|---|---|
| React | Frontend | Builds the HERA application interface. |
| TypeScript | Programming Language | Provides type-safe application development. |
| Node.js | Backend Runtime | Runs backend services. |
| Express.js | Backend Framework | Handles APIs and server routes. |
| SQLite | Database | Stores HERA records and analytics. |
| REST API / HTTP | Communication | Transfers data between system components. |
| JSON | Data Format | Structures transmitted data. |
| GroqCloud API | AI Platform | Provides AI inference services. |
| Meta Llama through Groq | LLM | Powers the HERA AI Assistant / LLM Agent. |
| Orpheus TTS through Groq | TTS | Generates spoken AI responses. |
| Charting Library | Visualization | Displays historical trends. |
| Arduino Framework | Embedded Software | Develops ESP32-S3 firmware. |
